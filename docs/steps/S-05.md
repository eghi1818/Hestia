# S-05 - Tombol tambah target menyimpan ke basis data

Tanggal: 2026-10-19

Cara kerja: live.js memasang pengait pada btnAddTarget. Saat ditekan, form dikirim
lewat POST /api/targets, lalu tampilan disegarkan dari API. Penanda __hestia_refresh
memungkinkan penyegaran dari luar.

Bukti:
```
$ GET /live.js (harus 200)
http 200
$ live.js memuat pengait simpan (harus ada)
1
$ POST target baru lewat API
http 201
$ jumlah target sekarang
{"ok":true,"service":"hestia","targets":3}
```
