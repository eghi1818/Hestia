# S-06 - Perbaiki pengait simpan dan tambah gerbang integrasi

Tanggal: 2026-10-19

Masalah: tombol Simpan target tidak punya id, sehingga getElementById("btnAddTarget")
selalu null dan pengait tidak pernah menempel. Nama kolom tipe juga salah (selType
seharusnya fType).

Perbaikan: menimpa window.addTarget langsung, karena tombol memakai onclick dan
addTarget adalah function declaration di skrip klasik.

Gerbang v4 menambah pemeriksa integrasi: setiap getElementById di live.js
wajib punya padanan id di index.html.

Bukti:
```
$ GET /live.js
http 200
$ live.js menimpa window.addTarget (harus 1)
2
$ index.html punya id fType (harus 1)
1
$ index.html punya id fDomain (harus 1)
1
$ jumlah target
{"ok":true,"service":"hestia","targets":3}
```
