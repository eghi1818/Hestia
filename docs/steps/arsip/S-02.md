# S-02 - Backend, database, endpoint target

Tanggal: 2026-10-19

## Tujuan
Hestia punya API dan basis data sehingga target bisa disimpan sungguhan.

## Yang dibuat
- app/db.py - koneksi dan skema SQLite
- app/main.py - API: health, targets CRUD, sajian dashboard
- requirements.txt - fastapi, uvicorn
- tools/serve.sh - jalankan layanan satu origin di port 8787

## Endpoint
GET    /api/health
GET    /api/targets
POST   /api/targets
GET    /api/targets/{id}
PATCH  /api/targets/{id}
DELETE /api/targets/{id}
