# S-07 - Tutup lubang pemeriksa integrasi

Tanggal: 2026-10-19

Masalah: pemeriksa integrasi v4 hanya mencari pola getElementById("x"), sehingga
rujukan lewat helper val("x") tidak diperiksa. Akibatnya #fType dan #fOwner lolos.

Perbaikan: pola diperluas ke (getElementById|val)("x"), dan jumlah rujukan dicetak
supaya lubang serupa langsung kelihatan.

Juga: tipe data uji dinormalkan agar cocok dengan opsi dropdown dashboard
(Situs sendiri / Mitra berizin / Internal company).
