# S-09 - Laporan balik dari browser

Tanggal: 2026-10-19

Masalah: terminal tidak bisa menjalankan live.js, sehingga keberhasilan sambungan
di browser tidak pernah terbukti. Hanya keberadaan teks yang diperiksa.

Perbaikan: tabel clientlog dan rute /api/clientlog. live.js melapor balik saat
halaman dimuat, saat target tersimpan, dan saat gagal.

## Bukti
```
$ GET /api/clientlog (harus 200)
http 200
$ POST /api/clientlog dari terminal (uji rute)
http 201
$ isi clientlog
[{"id":1,"waktu":"2026-10-19 04:03:05","peristiwa":"uji-terminal","rincian":"cek-rute"}]
```
