# S-03 - Perbaikan kompatibilitas dan penguatan gerbang

Tanggal: 2026-10-19

## Masalah yang diperbaiki
1. app/main.py memakai sintaks str | None yang butuh Python 3.10+.
   Diganti menjadi Optional[...] agar jalan di Python 3.8+.
2. Gerbang hanya mencetak kode HTTP tanpa menandai gagal, sehingga
   commit lolos saat layanan mati. Sekarang fail-closed.
3. Ditambah pemeriksaan kompilasi app/main.py di gerbang.
